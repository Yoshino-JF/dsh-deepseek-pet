# 姿态集（assets\poses\）— 素材约定

把**整张姿态图**丢进这个目录即可生效，不需要改代码；缺哪一张就自动回退到 v1 站立立绘，不会报错、不会空窗。

## 文件命名

| 文件名 | 姿态 | 什么时候出现 |
|---|---|---|
| `pick.png` | 被拎起来：**悬空、腿自然下垂、小嘴嘟哝** | 鼠标按住拖动时（松手落地 + 代码画的扬尘） |
| `doze.png` | 坐着打瞌睡（靠桌/抱膝都行） | 无互动超过 `sleepIdleSeconds`（默认 600 秒） |
| `handheld.png` | 坐着低头拿掌机玩 | 无互动超过 `gameIdleSeconds`（默认 90 秒）→ 同时**纯代码游戏屏**出现并自己演 |
| `meditate.png` | 盘腿冥想（「深度求索」） | DSH 在干活时（宿主忙 → 她入定），也可由我主动切 |
| `<上面任一>_t1.png` | **过渡帧**（可选，1 张就够） | 切到该姿态前先播 ~170ms，例如 `handheld_t1.png`＝单手把掌机举在空中 + 灯泡"有好点子"特效 |

`idle`（站立待机）不需要文件：直接用 `assets\{idle,blink,happy,worry,sleepy}.png` 那套 v1 立绘 + 呼吸/摇摆/浮动/眨眼。

## 硬性约定（不遵守会跳）

1. **同画布**：每张姿态图的画布尺寸必须和站立立绘一致（**720×1090**，透明 PNG）。尺寸不同会让窗口与她的位置跳动。
2. **脚底对齐**：所有姿态的"最低点"画在画布底部同一位置（站立立绘就是这么裁的），否则切换时人会上下蹦。
3. **洋红底抠图**：用纯 `#FF00FF` 平涂背景生成，再用 `build\pet-tools.exe key <in> <out> --t0 60 --t1 150` 抠掉 → `trim` → `scale 720`（原地站姿的立绘就是这么做的）。
4. **背景留白**：四周留 20–40px 余量，别让手/头发贴到画布边缘（生成模型很容易把边缘内容裁掉）。

## 一键对齐校验

```powershell
# 不透明内容框必须一致 + 50% 叠加无重影
powershell -File tools\pose-check.ps1        # （若尚未提供，用 tools\preview-map.ps1 看内容框）
```

## 验收开关（开发用）

```powershell
build\DeepSeekPet.exe --posetest handheld    # 启动即切成掌机姿态
build\DeepSeekPet.exe --scene --posetest doze
```

## 尺寸与对齐规则（2026-10-03 实测定稿）

**尺寸基准 = handheld.png（用户最满意的游戏状态）**，其余姿态以它为参照。

| 素材类型 | 尺寸基准 | 对齐方式 | 理由 |
|---|---|---|---|
| 坐姿（handheld / meditate / doze） | handheld 的头部尺寸 | **内容底边贴画布底边** | 坐着的人本来就是"脚/腿在地上"，底边对齐最自然 |
| 悬空类（pick 等不落地姿态） | 同上，**再乘 0.80** | **内容顶部对齐（头对齐）** | 悬空时头应停在正常高度、脚在空中；若按底边对齐，整个人会被压低一大截（实测叠加图双层影） |

**色调基准 = handheld**（实测头部区域均值 **131,131,181**）：pick / meditate / doze 已按通道增益调平到同一值；
调色只作用于头发色域，肤色、服装、贴纸、背景不动。备份在 uild\backup-poses-20261003-0150\。

**验证方法（推荐）**：同一窗口位置、同一裁剪坐标抓两张 → 50% 叠加 → 有重影就是没对齐。
⚠️ **不要用余额条当标尺**：干活中 余额 ¥53.67 比 余额 -- 长一截，条宽会随文字变化（踩过的坑）。

## 生成立绘：小属性核对清单（2026-10-03 固化，用户要求）

**背景事故**：早期"比耶"版本立绘生成时**头顶的小鲸鱼玩偶丢失**，导致该版本被整体放弃（素材已退役）。
用户明确要求：**生成立绘时必须逐项核对小属性**，不只对颜色与整体造型。

### 核对清单（每张新立绘必须逐项确认）

| # | 小属性 | 位置/形态 |
|---|---|---|
| 1 | **头顶蓝色鲸鱼玩偶** | 盘在头顶发髻上，鲸鱼尾巴朝右、白肚皮朝下 |
| 2 | 白色荷叶边头饰 | 环绕头部一圈的白色波浪边 |
| 3 | 左右蓝色蝴蝶结（带金扣） | 头部两侧，各一个 |
| 4 | 白色小鱼发饰 | 左侧发际（观众视角右上方），鲸鱼帽下方 |
| 5 | 颈前蝴蝶结 + 宝石坠 | 深蓝领结，中央嵌蓝色宝石 |
| 6 | 围裙上的小鲸鱼刺绣 | 白色围裙右下角 |
| 7 | 蓝色鲸鱼尾巴 | 从裙摆右后方伸出（观众视角右侧） |
| 8 | 白袜 + 深蓝圆头鞋 | 双脚 |
| 9 | 手势 | **现行标准：双手交叠在小腹前**（旧版的"提裙摆"已废弃） |
| 10 | 配色 / 画幅 | 深蓝女仆装 + 白围裙 + 蓝紫长发；720×1090 画布、底边对齐 |

### 生成流程（必须遵守）

1. **以现役素材为源图**：用 edit_image 并显式传 source_path（指向 ssets\ 或 ssets\hi\ 里的现役立绘/高清模板），**不要凭文字描述重新生成角色**——那必然丢小属性。
2. **显式指定 spect_ratio**（本角色用 3:4），否则输出比例可能与源图不一致。
3. **一次只改一处**（只换表情／只换手势），其余全部写进 prompt 的"保持不变"清单里，并**把小属性逐条点名**（例如"头顶那只蓝色鲸鱼玩偶必须在原位原样保留"）。
4. **同一套立绘共用一个源图**：四张站立表情（idle/blink/worry/sleepy）必须以**同一张身体图**为源，改身体时必须四张一起重出，否则待机与眨眼之间会出现**身体跳变**。
5. **提交前出对照图**：新旧并排 + 逐项核对小属性 + 交用户确认；确认后才落盘，旧版进 .trash（可逆）。

### 处理链（本项目实测可用）

`
pet-tools key <源图> <out.png> --t0 60 --t1 150     # 洋红底抠图
pet-tools trim <out.png> <trim.png>                  # 裁到内容边界
# 再缩放到 720x1090、水平居中、底边留 4px（tools\pose-fit.ps1 或手写 System.Drawing）
`
**验收口径**：四张同套素材的缩放比应当一致（如新站立四张均为 0.927–0.928），**缩放比不一致就说明构图没对齐**。
