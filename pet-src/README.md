# DeepSeek 桌宠（DeepSeekPet）

一只悬浮在 Windows 11 桌面上的**蓝鲸女仆桌宠**，实时显示 DeepSeek 开放平台**账户余额**，
由 DSH 插件从凭据库取 Key、查余额后经回环接口喂给它。

- 桌宠本体：`build\DeepSeekPet.exe`（C# + WPF，纯 .NET Framework 4.x，**零第三方依赖**）
- DSH 插件：`..\deepseek-pet-plugin`（bundle `dsh-deepseek-pet`，工具 `pet_balance` / `pet_control`）
- 素材：`assets\{idle,blink,happy,worry,sleepy}.png`（透明 PNG，含 5 种表情）
- **版本与路线图**：见 [DEVLOG.md](DEVLOG.md)（当前 **v0.1.11**）

```
DSH 宿主插件 (dsh-deepseek-pet)          桌宠 (DeepSeekPet.exe)
  ctx.credentials.resolve(DEEPSEEK_API_KEY)     │
  GET https://api.deepseek.com/user/balance     │  每 5 秒
  HTTP 127.0.0.1:47831/state ───────────────────┘  取余额 + 留言
  spawn / kill ─────────────────────────────────▶  透明置顶窗（总在最前、不进任务栏）
```

## 快速开始

```bat
:: 1) 编译（首次或改过源码后）
D:\DeepSeek\deepseek-pet\build.cmd

:: 2) 装 DSH 插件（在 DSH 里让 Agent 执行，或面板 设置→插件→安装本地 bundle）
plugin_manager install_bundle  D:\DeepSeek\deepseek-pet-plugin

:: 3) 单独运行桌宠（插件没装也能跑，只是显示“离线 + 上次余额”）
D:\DeepSeek\deepseek-pet\run-pet.cmd
```

插件装载 3 秒后会自动把桌宠叫起来；也可以在对话里直接说「把桌宠叫起来」。

## 交互

| 操作 | 效果 |
|---|---|
| **按住 ≥180ms 拖动** | **仅"站着待机"姿态**会进入**被拎起**（`pick`）：暂停游戏（屏幕与光柱收起，场景状态不变）→ 拖动移动位置 → 松手回到原姿态（跳过过渡帧）并**位置钉住**（v0.2.1）。**拿掌机 / 打瞌睡 / 冥想等坐姿下拖动＝单纯搬动她**，不改姿态、不动屏幕与光柱（v0.2.2） |
| **快速单击（<180ms）** | **互动**：蹦一下 + **头顶星星闪光** + 随机台词（**无落地粒子**）—— 不会误触发拎起（v0.2.2 起点击效果为星星闪光） |
| 双击 | 开心表情 + 蹦跳 + 台词 |
| 滚轮 | 放大 / 缩小（120–460 px） |
| 右键 | 菜单（**v0.2.2 起分为 4 组**）：**余额**（立即刷新余额 · 显示余额徽章）/ **她（状态 / 表情 / 动画）**（让她做什么 · 表情 · 摇摆呼吸 · 海底气泡）/ **游戏**（游戏屏 · 游戏画面 · 招一只苦力怕（彩蛋） · 只看游戏屏（挂机模式））/ **外观与位置**（书桌场景开关已废 · 大小 · 回到右下角 · 总在最前）/ 底部：关于 / 状态 · 退出桌宠 |
| 点游戏屏 | 单击换游戏 · **双击场景区**：MC 招苦力怕 / galgame 切下一位角色 · galgame 点选项 = 做选择 |
| 「招一只苦力怕」（彩蛋） | 游戏屏开着 → 在游戏里招（苦力怕探头）；**游戏屏没开 → 招到她身边**（像素苦力怕从一侧走过 + 台词 + 担心表情），**不会强行打开游戏屏**（v0.2.2 修） |

**表情系统（v0.2.2）**：`idle`（含眨眼）/ `worry` / `sleepy` 三态，**比耶（happy）立绘已退役**（风格与其它立绘差距过大）。
姿态与表情是**两套独立系统**：「让她做什么」管姿态（站 / 掌机 / 打瞌睡 / 冥想 / 拎起），「表情」管脸（普通 / 担心 / 困倦），可任意组合 —— 所以会出现"站着但一脸担心"。
⚠ 排查提示：`worry` 的**嘟嘴脸**与 `pick` 姿态的嘟嘴**在 260 DIP 下极易混淆**（身体相同、只有脸不同，见 `build\which-face.png` 对照法）。

**游戏屏怎么关（v0.2.2 起两条路径共用同一收尾动画）**：
- **状态切换**（右键「让她做什么」从"拿掌机玩"切到别的）→ 立刻播**关屏动画**（屏幕缩放淡出 + 光柱淡出）。
- **被叫去干活**（DSH 开始干活）→ 先进入 **`interrupted`**：屏幕**不关**，叠一层**暂停条 + 白闪 + 收屏亮线**，各游戏屏演自己的"惊一下"（MC 苦力怕探头 / 2D 横版她僵住发抖 / galgame 冒汗"我这就关掉"）；随后才真正关屏（同一动画）并转入冥想姿态。
- 开发验收：`--shutdowntest`（启动 4s 后自动走一遍 gaming→idle）。

**状态与锁定（v0.2.1）**：右键「让她做什么」手动选定的姿态会**锁死**（冻结场景机，不再被余额/工作事件切走）；选「跟着场景（自动）」恢复跟随。
切到非掌机状态会同步**收起游戏屏与光柱**（走 `SetScene`，不是只调透明度）；切到「拿掌机玩」会走一遍**开机节奏**（设备关机 170ms → 屏幕淡入 + 光柱淡起）。

### 游戏屏（Minecraft 第一人称，v0.0.2 起 / v0.0.3 加强）

不依赖任何美术素材，全部由 `src/McScreen.cs` 用像素矩形画进 `WriteableBitmap`（120×80 像素 ×2 最近邻放大）：
砍树（树干裂纹）→ 方块碎裂飞散 → `原木 +1` → 新树 → 按 `creeperChance` 触发苦力怕（逼近 + 嘶嘶 + 白闪）
→ **You Died** 红屏 + `Respawn` → 回到砍树。

画面里带一整套 MC HUD（v0.0.3）：`NN FPS / XYZ / BIOME` 三行 F3 文字、准星、九宫热键栏（含选中高亮与物品图标）、
红心 + 饥饿 + 经验条、右上小地图、方块化树冠与树皮、方形太阳、地平线雾。**没有画第一人称手持物**——
在 120×80 下斧头/手臂都认不出来（详见 DEVLOG 10.2 的试错记录）。

**调屏幕动画的姿势**（不用截图猜相位）：

```bat
build\DeepSeekPet.exe --mcdump D:\tmp\sheet
:: 输出名自动带版本号，例如（v0.0.15）：
:: sheet-v0.0.15-chop.png = 伪 3D 砍树 16 帧；sheet-v0.0.15-peek.png = 苦力怕探头 16 帧
:: sheet-v0.0.15-side.png = 2D 横版走 16 秒（含刷怪、砍树、被炸）
```

**换 galgame 立绘/背景**（一张三并排设定图 → 三张）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\split-cast.ps1 `
    -Src <设定图.jpg> -OutDir assets\vn -Names cloud,book,star -MaxWidth 520
```

抠图参数：`pet-tools key <in> <out> [--t0 60] [--t1 150] [--despill 0.85]`。
`--despill` 控制"去品红溢色"的强度，**0 = 完全不动原色**（边缘可能留一点品红）。
注意别用反预乘那套公式去溢色：对 JPEG 压缩过的柔和阴影会把 G 通道算爆，紫色会被染成绿色（详见 DEVLOG 10.9）。

**自动化点击 / 截图坐标**：桌宠启动 1.2 秒后会把游戏屏的物理矩形写进 `%APPDATA%\deepseek-pet\pet.log`
（`screen rect physical …`），每次点屏幕也会记一行 `screen click … consumed=…`。

### 三块游戏屏（v0.0.4 起可切换，v0.0.5 加入 galgame）

**点游戏屏**：单击 = 换下一个游戏 · 双击 = 招一只苦力怕 · galgame 屏里**直接点选项就是做选择**
（右键菜单 →「游戏画面」也能切；配置项 `game` = `fp` | `side` | `vn`）。

| 画面 | 内容 |
|---|---|
| 伪 3D（`src/McScreen.cs`） | **纯砍树**：树冠裂纹 → 方块碎裂 → 原木 +1；苦力怕会**横着躺**从左边或右边探进来（位置高度随机、停 1.4s 再缩回，**带冷却：狂点也只会有一只**） |
| 2D 横版（`src/McSide.cs`） | 鲸鱼娘在方块世界向右走：砍树（原木 +1）、挥剑清怪、**骷髅射箭（可见抛物线，−1 心）**、**她也偶尔回弓射箭**、血少时**掏食物咀嚼回血**（不能移动、会被打断）、苦力怕贴身 **−3 心**、血量归零 → You Died → **整关重载**（回起点、树/怪/箭清空、血与食物复原、怪物重新从最右侧来） |
| galgame（`src/McVn.cs`） | AI 拟人角色的对话框 + **可点选的选择支**（**每位角色各自记好感度** ±1、分支回复）；每个角色配一张背景；**双击场景区切下一位角色**；满好感演出（满屏飘心 + 比心）与归零演出（十字青筋 + 红框脉冲） |

### 姿态集（v0.2.0 起，现行方案）

**一句话**：她是一张张**整图姿态**在切换，动作全部来自整体变换与代码特效 —— 不再对生成图做任何局部像素操作。

| 姿态 | 素材 | 什么时候出现 | 怎么"活" |
|---|---|---|---|
| 站立待机 | `assets\{idle,blink,happy,worry,sleepy}.png`（v1 那套） | 默认 | 呼吸 ±1.5% / 摇摆 ±1.8° / 浮动 ±10px / 眨眼层 |
| 被拎起 | `assets\poses\pick.png` | 鼠标按住拖动时（松手落地 + 代码画扬尘） | 悬空小幅摆动 + 跟随拖动 |
| 打瞌睡 | `assets\poses\doze.png` | 无互动 > `sleepIdleSeconds`（默认 600s） | 缓慢起伏 + Zzz 粒子 |
| 拿掌机玩 | `assets\poses\handheld.png` | 无互动 > `gameIdleSeconds`（默认 90s），或菜单手动切 | 整体浮动 + **纯代码游戏屏**悬浮在上方自己演 + **掌机投影光柱**（见下） |
| 深度求索 | `assets\poses\meditate.png` | DSH 在干活时自动入定 | 整体浮动 + 气泡台词 |
| 挂机模式 | ——（她收起） | 右键「只看游戏屏」 | 只留纯代码游戏屏 |

**掌机投影光效（v0.2.1）**：她拿掌机时，从**掌机上边缘**向上打出一道光柱到游戏屏下沿。
- **身前单层**（背后层已弃用，避免"光在她身后"）；**水平羽化**（`OpacityMask`）＋ **双端淡出**（底 6 / 峰值 88 / 顶 22）→ 没有硬边界
- **图层顺序：立绘 → 光柱 → 游戏屏 → 气泡**（画面与文字优先，光只做氛围）
- 光柱里每秒 2–3 颗**上升微尘**；掌机处一圈柔光（45%）
- **设备锚点**用 `assets\poses\<姿态>.json` 按比例分数记录（`handheld.json`：`deviceTop 0.548 / deviceWidth 0.458 / deviceCenterX 0.507`）→ 光柱根＝掌机上边缘，窗口缩放时幅度自动一致
- **开机节奏**：切到掌机姿态＝设备关机 170ms（屏幕与光收起）→ 屏幕缩放淡入 + 光柱淡起
- **调试**：`--beam on|off|debug`（debug 用实心洋红画出几何，用于定位"看不见/位置不对"）

**素材约定**（详见 `assets/poses/README.md`）：720×1090 透明 PNG、洋红 `#FF00FF` 底生成后抠图；
**尺寸基准 = 站立立绘（"整个人"体量为准）**：坐姿三张＝内容**底边对齐**，悬空类（`pick`）＝**100% + 内容顶部对齐（头对齐）**；
**色调基准 = 站立立绘（头发区均值 151,150,188）**，四张姿态已对齐（`pick` 曾因 G 通道低 9 而"偏紫"）；
生成认身份用 v1 站立立绘当参考图；处理链：`pet-tools key` → `trim` → 贴画布（`tools\pose-fit.ps1`）。
**验证尺寸用 50% 叠加法**（同窗口位置抓两张 → 叠加 → 有重影即未对齐）；⚠ **不要用余额条当标尺**（`干活中` 三字会把它拉长）。
**加新姿态不用改代码** —— 丢一张 `assets\poses\<名字>.png` 进去即可（过渡帧机制仍保留，但**现行方案不再使用**：`handheld_t1.png` 已退役）。
**开发验收开关**：`--posetest <pick|doze|handheld|meditate>`、`--screenonly`、`--presstest <帧|none>`、`--beam <on|off|debug>`。

### 一体化桌宠场景（R2a → v0.1.10 起改版，`assets/desk/`）

右键菜单 →「**书桌场景**」开关（配置项 `sceneMode`，会记住）。开启后**整张立绘就是你给的那张桌宠预览图**：
她自己带着桌子、鼠标垫、鼠标与键盘，桌宠只负责把"该动的小块"叠上去 —— **不切层**（切线会留硬边＝割裂）。

- **底板**：`assets/desk/sit_watch.png`（预览图抠掉洋红底，1024×1020）。`sit_look.png` 是同一尺寸的第二态位。
- **可动件 = 全画幅补丁帧**（同尺寸透明 PNG，只有动的那一小块不透明，因此天然逐像素对齐、代码里不需要坐标）：
  - `press_d / press_a / press_w / press_space.png` —— 键帽按下（下移 5px + 压暗 26% + 顶部插槽暗条）；游戏里走路/敲键盘时点亮
  - `press_mouse.png` —— 鼠标下沉 6px；砍树/攻击/点击时点亮
  - `face_blink / happy / worry.png` —— 表情差分（脸部差集补丁，缺哪张就回退到底图的常态脸）
- **表情怎么来**：常驻情绪（余额低＝担心、久无互动＝困倦、点击＝开心）+ 眨眼（每 2.6–6.2 秒短暂点亮 150ms）。
- **浮动已关闭**（用户要求）：场景模式下浮动/摇摆/呼吸全部归零，改用"按键补丁帧"表达她在操作。
- **头顶不再被裁**（v0.1.10 修的 bug）：气泡行恒定预留 88 DIP，窗口高度始终把它算进去，立绘顶部不会再被顶出窗口上沿。
- **开发用验收开关**：`--presstest <d|a|w|space|mouse|none>`、`--facetest <blink|happy|worry|sleepy|look|none>`、`--scene`。
- **素材缺失自动回退**：`assets/desk/` 里少文件时只提示一句并关掉开关，桌宠照常运行。
- **差分帧生成**：`tools\make-press.ps1`（键鼠按下）、`tools\make-face-patch.ps1`（表情：变体图 − 底图 → 阈值 → 去碎片 → 膨胀 → 补丁帧）、`tools\keys-detect.ps1`（键帽坐标）。

### galgame 素材（`assets/vn/`）

**默认素材全部由本项目自行生成**：保留"一眼认出是谁"的配色与气质，名字用安全占位（`CHAT` / `CLOUD` / `GEM`），
不含任何商标、logo 或文字。想换成自己喜欢的立绘，把图片丢进 `assets/vn/local/` 即可覆盖，无需改代码：

```
assets/vn/
  chat.png   cloud.png   gem.png            # 立绘（自带 alpha）：银发龙角 / 橙发抱书 / 猫耳
  bg_chat.jpg  bg_cloud.jpg  bg_gem.jpg     # 对应背景
  love_<id>.png  angry_<id>.png             # 可选：满好感 / 生气的专属立绘（没有就用普通立绘）
  local/                                     # 本机自用档（不进仓库）：同名的 png/jpg 优先于此
```

看情绪演出（开发用）：`build\DeepSeekPet.exe --screen on --game vn --vnmood love`（或 `angry`）。
看横版屏战斗（开发用）：`build\DeepSeekPet.exe --screen on --game side --sidetest`
（一开就摆好"血 2 心 + 3 份口粮 + 骷髅在射程内"，很快能看到射箭 / 受击闪红 / 吃东西回血）。

**省电（v0.0.3 实测）**：待机 23.9 % → **1.3 %** 单核、游戏屏常开 24.5 % → **0.65 %**（原因：把常驻 WPF 动画改成 9 FPS 定时器驱动 + 代码模拟粒子）。

**R2d「被叫去干活」统一演出（v0.0.9）**：宿主检测到"用户主动发起的回合"（`agent/inbox/inserted` 后 10 秒内 `agent/status` 变 `running`）就发一条 `work-start`
事件；三块游戏屏**先各自演"惊一下"**（MC＝招牌苦力怕炸死／横版＝僵住发抖＋冒汗／galgame＝冒汗＋"我这就关掉"），
然后**统一收尾**：`PAUSE` 暂停条滑入 → 白闪抖动 → 画面竖向收拢 → 亮线熄灭 → 收起悬浮屏 →
换成困倦脸说"……好吧，我去干活了。（不情愿）"，徽章显示「干活中」。事件走长轮询推送，实测从触发到起反应 < 100ms。
| 托盘图标 | 显示·隐藏 / 立即刷新 / 退出 |

**表情是怎么选的**（`moodOverride=auto` 时）：余额低于阈值或账户不可用 → 担心；6 分钟没互动 → 困倦；
充值到账或点击 → 开心；其余 → 普通。每次说话、点击都会眨眼。

## 桌宠配置

`%APPDATA%\deepseek-pet\config.json`（首次运行自动生成，退出时写回）：

| 字段 | 默认 | 说明 |
|---|---|---|
| `stateUrl` | `http://127.0.0.1:47831/state` | 状态接口（插件端口改了要同步改这里） |
| `spriteWidth` | `220` | 立绘宽度（DIP），高度按比例 |
| `x` / `y` | 右下角 | 窗口位置（DIP，-1 = 回默认） |
| `topmost` | `true` | 总在最前 |
| `showBalance` | `true` | 显示余额徽章 |
| `particles` | `true` | 海底气泡特效 |
| `sway` | `true` | 呼吸 / 摇摆动画 |
| `opacity` | `1.0` | 整体透明度（0.25–1.0） |
| `pollSeconds` | `5` | 取状态周期（`longPollSeconds>0` 时只作兜底） |
| `longPollSeconds` | `25` | 长轮询：请求挂起最多这么久，宿主有事件立刻返回（反应 <100ms）；`0` = 退回普通轮询 |
| `screenMode` | `auto` | 游戏屏：`auto` 久不互动就开玩 / `on` 常开 / `off` 关闭 |
| `game` | `fp` | 游戏画面：`fp` 伪 3D / `side` 2D 横版 / `vn` galgame（也可点屏幕切换） |
| `gameIdleSeconds` | `90` | 无互动多久开始玩游戏（右键「游戏屏」可临时切换） |
| `sleepIdleSeconds` | `600` | 无互动多久趴睡（换 sleepy 表情 + Zzz） |
| `creeperChance` | `0.08` | 每砍倒一棵树后被苦力怕炸的概率（调 1.0 可以连着看演出） |
| `lowBalance` | `10` | 低余额阈值（插件也会下发同名值） |
| `moodOverride` | `auto` | 强制表情：auto/idle/happy/worry/sleepy |
| `assetsDir` | 空 | 自定义立绘目录（留空 = exe 同级的 `assets`） |

日志：`%APPDATA%\deepseek-pet\pet.log`（只记失败与关键事件）。

## 换立绘 / 重做素材

素材处理工具 `build\pet-tools.exe`（源码 `src\tools\PetTools.cs`）：

```bat
:: 抠掉纯色背景 → 透明 PNG（顺便去小碎块 + 裁边 + 去背景溢色）
pet-tools.exe key  raw.jpg  idle.png  --t0 60 --t1 150
:: 缩小到 720 宽（高质量重采样）
pet-tools.exe scale  idle.png  idle.png  720
:: 看尺寸与不透明占比
pet-tools.exe info  idle.png
```

生成立绘的提示词要点（本项目实测有效）：人物立在**纯品红 #FF00FF 平涂背景**上、四周留白、
不要文字/边框；换表情时**以同一张图作为源图**，只描述表情改动，其余「不要重绘、不要移动」。
**鲸鱼只有一条尾巴**——第一版生成器把尾鳍镜像成左右各一条，重出时才改对。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 徽章显示「离线 余额 --」且是灰点 | 插件没跑或端口不对：浏览器打开 `http://127.0.0.1:47831/health` 自检；DSH 没开时显示上次缓存的余额 |
| 徽章数字发灰不动 | 数据是缓存（`stale`）：点右键「立即刷新余额」或 `pet_control action=refresh` |
| 改了插件 `index.js` 没生效 | 同包替换返回 `restart-required`，重启 DSH 后加载新世代 |
| 双击 exe 没反应 | 单实例互斥：已经有一个在跑了（托盘里能找到） |
| 端口被占用 | 改 `cordis.patch.yml` 的 `port`，同时改 `config.json` 的 `stateUrl` |
| 想彻底卸载 | `plugin_manager remove_bundle dsh-deepseek-pet`；桌宠关掉托盘→退出，再删除本目录 |
